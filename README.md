# SLGA_BKS
Best-known solution records for the Capacitated Minimum Spanning Tree Problem with Time Windows (CMSTPTW), including results obtained by SLGA.
 #Repository Contents
`3sm-bks.json`**: Reference BKS data associated with the 3SM method.
`solutions/`**: Solution files containing the tree structures associated with the reported results.
`verify_solution_compatible.py`**: Python script for checking solution validity and consistency.

These files are provided to support reproducibility and facilitate future comparisons on CMSTPTW benchmark instances.
